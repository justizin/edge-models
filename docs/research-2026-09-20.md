# Landscape research, 2026-09-20

Web research done at project start by a Claude subagent. Facts here drive the model manifest and the per-tier docs; items flagged unconfirmed are listed at the end. Source URLs are kept inline.

## 1. Small open-weight LLMs, GGUF-available

Key landscape shifts since 2025: **Qwen3.5** (Feb–Mar 2026, dense 0.8B/2B/4B/9B + 35B-A3B), **Gemma 4** (Apr 2 2026, E2B/E4B/12B/26B-A4B/31B, now Apache 2.0), **Qwen3.6** (Apr 2026, 27B + 35B-A3B only), **Granite 4.1** (May 2026, dense 3B/8B/30B), **Qwen3.8** (Aug 2026, 27B + 2.4T-A95B + Flash-Next 125B-A6B, nothing small), **Meta Muse Glimmer 30B** (Aug 10 2026, Apache 2.0, no small variants). No new small Llama, no SmolLM4, no Phi-5. "gpt-oss-8b" does not exist; OpenAI's HF collection lists only gpt-oss-20b (21B/3.6B active) and 120b.

## 2. llama.cpp Vulkan on Tahiti (GCN 1.0) via RADV

- Works, with caveats. RADV reports Tahiti as `fp16: 0 | warp 64 | shared 32768 | int dot: 0 | matrix cores: none`. RADV exposes 16-bit storage unconditionally on GFX6 (llama.cpp's hard requirement), 8-bit storage, BDA; no shaderFloat16, no coopmat, no int-dot. Vulkan 1.3 conformance for GFX6/7 landed in Mesa 24.3; Debian 13 ships Mesa 25.0.7. Valve's Timur Kristóf committed to continued GCN1 support (EOY-2025 post).
- Known bug: `vk::DeviceLostError` / "CS cancelled, context lost" with full offload once context passes ~500 tokens (llama.cpp #19610, #19615, Feb 2026, dual FirePro D700). Workaround: `RADV_DEBUG=novm,syncshaders,zerovram` plus `-ub 256` (`syncshaders` is the key flag). On Pitcairn: keep `--flash-attn` off (79% regression, fp32 fallback), never `--no-kv-offload` (garbage), all-or-nothing offload.
- Env vars: `GGML_VK_DISABLE_F16`, `GGML_VK_DISABLE_COOPMAT`, `GGML_VK_DISABLE_INTEGER_DOT_PRODUCT` are no-ops on Tahiti. Useful: `GGML_VK_VISIBLE_DEVICES`, `GGML_VK_FORCE_MAX_ALLOCATION_SIZE`, `RADV_PERFTEST=nogttspill`.
- tok/s reports: 2x Tahiti 7B Q4_0 pp512 95 / tg 25 (discussion #10879); 2x Pitcairn Qwen2.5-3B Q4_K_M ~30 tg, pp ~75; 14B Q4_K_M with workarounds 11 tg / 70 pp. Single R9 280X on 1–4B Q4: ~25–40 t/s is an extrapolation.
- Kernel: Debian 13's 6.12.107 has `CONFIG_DRM_AMDGPU_SI=y`; on 6.12 radeon still claims SI by default, so `radeon.si_support=0 amdgpu.si_support=1` is still required. Linux 6.19 flipped the default. RADV needs amdgpu KMS.
- OpenCL: not viable (Clover removed in Mesa 25.2, llama.cpp OpenCL backend targets Adreno/Intel). ROCm/AMDVLK don't support GFX6.

## 3. Apple Foundation Models + iOS local LLMs

- Model (iOS 26): ~3B dense, 2-bit QAT weights, 4-bit embeddings, 8-bit KV, LoRA adapters. iOS 27 (shipped 2026-09-14) brings AFM 3: "Core" (new 3B) and "Core Advanced" (20B sparse, 1–4B active, iPhone 17 Pro/Air). Apple's own model decodes ~85 tok/s on iPhone 17 Pro.
- Devices: Apple Intelligence floor unchanged: A17 Pro+ iPhones (15 Pro, all 16/17 incl. 16e/17e), iPad mini A17 Pro, M1+ iPads/Macs. A16 and older excluded; 8 GB RAM minimum.
- API: `SystemLanguageModel.default`, `.availability`, `LanguageModelSession(instructions:tools:)`, `respond`/`streamResponse`, `@Generable`/`@Guide` constrained decoding, `Tool` protocol. iOS 27 adds image input, `contextSize`, `tokenCount(for:)`, `PrivateCloudComputeLanguageModel`, a `LanguageModel` protocol so MLX models can back a session, and a Python SDK.
- Context: iOS 26 = 4096 tokens combined per session; iOS 27 on-device = 8192. Inference serialized system-wide.
- Classification/log tagging: explicitly in-scope (content tagging, classification, extraction via `@Generable` enums). Apple says not for world knowledge, code generation, math.
- Free Apple ID: no entitlement documented for the base model (only adapters and PCC need paid membership). Personal-team 7-day sideload should work (inferred, not confirmed). Simulator works on macOS 26+ Apple-silicon hosts.
- Apps: PocketPal AI (llama.cpp, open source); LLMFarm pulled from App Store Aug 2025 (source only); Private LLM ($4.99, mlc-llm); Locally AI acquired by LM Studio (Apr 2026), relaunched as "Locally by LM Studio" (MLX + Foundation Models); Enclave (MLX + llama.cpp). On A19 Pro, MLX-Swift beats llama.cpp Metal by 1.3–1.6x on decode. Memory: `increased-memory-limit` entitlement gives ~4.7 GB usable on 8 GB phones; ~2–2.5 GB on 6 GB; ~1–1.5 GB on 4 GB.
- tok/s (Metal, Q4): TinyLlama 1.1B: A15 39, A16 54, A17 Pro 57, A18 70, A19 Pro 87; Phi-2 2.7B: A15 17, A17 Pro 25, A19 Pro 36. iPhone 16 Pro Llama 3.2 1B ~51, 3B 12–18, Gemma 3 4B 7–10; iPhone 17 Pro Gemma 3 1B 35–45, Llama 3.2 3B 16–22, Qwen3.5-2B 39 (llama.cpp) vs 61 (MLX); iPhone 14 Pro Gemma 3 1B 20–28, Llama 3.2 3B 7–11.

## 4. Raspberry Pi 5 / Pi 4 / Hailo-10H

- Pi 5 constraints: 17.1 GB/s LPDDR4X theoretical, ~5 GB/s measured; Cortex-A76 has dotprod + FP16 but no i8mm/SVE. Build with `-DGGML_NATIVE=ON`; generic arm64 binaries are ~10x slower. Q4_0 gets runtime dotprod repacking; Q4_K_M is the usual quality default.
- Pi 5 generation tok/s (Q4_K_M unless noted): Qwen3-0.6B Q8 21.5; gemma3:270m 22–23; gemma3:1b ~10; Llama 3.2 1B 17.8 (native llama.cpp); Qwen3-1.7B 5.4 (Q8 8.7); SmolLM2-1.7B 6.9; Gemma 4 E2B 7–7.6; Llama 3.2 3B 4.5–5.5; Gemma 3 4B 3.5 (QAT 5); Qwen3-4B 4.0; Phi-4-mini 4–5; Llama 3.1 8B ~2. pp512 ≈ 30–60 t/s for 1.5–3B, ~100 for 1B Q4_0. 8 GB vs 16 GB: no speed difference. Vulkan on VideoCore VII: 0.15 t/s, not planned (#26213).
- Pi 4: 2–3x slower; A72 lacks dotprod. >15 t/s only for ≤135M models, <5 t/s for ≥1B (arXiv 2511.07425).
- Hailo-10H / AI HAT+ 2: launched 15 Jan 2026, $130, Pi 5 only, 8 GB on the HAT, 40 TOPS INT4. `apt install hailo-h10-all`, `hailo-ollama` REST server. Official: Llama 3.2 1B 9.9 t/s, Qwen2.5-Coder-1.5B 8.1, Qwen3-1.7B 4.8 (A8W4, 2K ctx). Independent reviews: decode slower than Pi 5 CPU, but prefill/TTFT much faster (320 ms vs 2 s), offloads host RAM/CPU, system power 7 W vs 11 W. Max model ~1.7B. Hailo-8/8L: vision only.
- 2025–26 hardware: Pi 5 16 GB (price rose to ~$305 after DRAM-driven increases); Pi 5 1 GB $45; CM5 16 GB; Compute Module Zero (Jan 2026); Pi 500+ (Sep 2025); Pi 4 3 GB SKU (Apr 2026). Pi 6 not before early 2028, no NPU.

## 5. Third-party Linux on switch NOS + free virtual images

**Arista EOS:** EOS 4.32+ is AlmaLinux 9-based (RHEL9-compatible userland). `bash` from CLI; RPM/SWIX extensions; persistence via `/mnt/flash/rc.eos`; Python 3. Docker is not bundled (SWIX from the portal); EOS ~4.30+ has a native `container-manager` CLI (image load from flash, `memory hard-limit`, `cpu shares`, `on-boot`, privileged mode; config survives upgrades). Hardware is all x86: 7050X3 8 GB; 7280R3 quad-core Atom 16 GB (K/A SKUs 64 GB + 120 GB SSD); 720XP/722XPM dual-core x86, 4 GB; 7010T 4 GB. cEOS-arm exists for Apple-silicon lab hosts only. Current trains 4.33M–4.36F.

**Cisco NX-OS (Nexus 9000):** Guest Shell 4.x = Rocky 9 / Python 3.9 (NX-OS 10.4+); defaults CPU 1% / 400 MB / 200 MB rootfs, max 620% / 3,840 MB / 2,000 MB via `guestshell resize`; disabled by default on 4 GB boxes. `feature bash-shell` + dnf from devhub.cisco.com; RPMs persist in `/bootflash/.rpmstore`. Docker CE 18.09 bundled, needs ≥8 GB RAM, storage carved from bootflash (2000 MB default), `service docker start` + `chkconfig`, host networking supported, recommended `--cgroup-parent=/ext_ser/` (25% CPU/core). All x86 (Broadwell-DE/Xeon-D). RAM: 9300-EX 24 GB; 93180YC-FX up to 32 GB; 93180YC-FX3 16 GB; NX-OS idle ~6.3 GB on a 16 GB box.

**Cisco IOS-XE Catalyst 9000 IOx:** native Docker images since 16.12.1; DNA Advantage license required; 9200 and UADP-2.0 9500 not supported. Caps: 9300 = 2 GB RAM, 25% CPU (2 vCPU), 120 GB USB 3.0 SSD in rear port; 9300X = 8 GB, 4 vCPU; 9400/9500-HP/9600 = up to 8 GB, 25% CPU, M.2 SATA SSD.

**Juniper Junos:** FreeBSD 12 base from 21.1; FreeBSD 14 from 24.2R1. `start shell [user root]`; **veriexec blocks unsigned binaries: no third-party static binaries, no Linux compat.** On-box Python 3 (`set system scripts language python3`), root-owned unsigned scripts. JET: unsigned = Python only; signed C/C++ need a Juniper cert + JET VM. **Junos Evolved** (Linux, Yocto; 24.4 = kernel 5.15.164): ACX7k, PTX10k, QFX5130/5220/5230/5240/5700 only; no EX runs Evolved. Docker present (enable `docker.service`), images in `/var/extensions`, default limits 2 GB RAM / 20% of one core (tunable in `/etc/extensions/platform_attributes`), `--net=host`, persists across upgrades; native binaries must be IMA-signed.
